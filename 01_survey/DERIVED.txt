DERIVED FILES AND WHAT THEY WERE BUILT FROM

Both files in this folder beside the HTML are generated from it. Nothing stops
them going stale except this record: tools/check.py (C18) recomputes each hash
and fails when a derived file no longer matches its source.

Hashing the source rather than comparing timestamps means an unrelated edit
elsewhere in the survey does not raise a false alarm, and a real change to the
diagram does not slip through because a file happened to be touched.

Rebuild commands are in MAINTENANCE.md. After rebuilding, update the hash here.

    file || source || sha256 of that source
