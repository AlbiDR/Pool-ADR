This file is the single place where the numbers live. tools/check.py reads it and
verifies the rest of the repo against it, so a figure cannot quietly drift in one
file while staying right in another.

Edit a value HERE first, then run:

    python3 tools/check.py

and it will tell you every file that still carries the old one.

Format. Lines are "key = value" inside a block. Blank lines and lines starting
with "#" are ignored. Nothing else in the repo parses this file, so prose in it
is free.

NEVER
=====
Strings below are wrong and were corrected. The checker fails if any of them
reappears anywhere. Each line is:

    string || why it is wrong [|| except: paths] [|| unless: nearby phrase]

FACTS.txt itself is always exempt, otherwise this list would fail on its own
contents. "unless" is the important one: this survey deliberately records its own
corrections in the text, so a banned phrase is fine where it sits next to a label
saying it was superseded. It fails only when asserted straight.

The point of the list is that a future edit cannot quietly reintroduce a mistake
this survey has already worked through.
